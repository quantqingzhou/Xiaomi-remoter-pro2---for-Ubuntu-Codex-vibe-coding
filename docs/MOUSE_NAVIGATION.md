# Codex 与微信的鼠标操作

此功能随 `0.1.0-alpha.7` 预发布版提供。它是可选功能，旧配置默认关闭。第一阶段提供移动、点击、右键和滚动；不提供拖拽或截图框选。

## 启用与使用

打开“小米遥控器按键设置”，展开右侧“鼠标操作 · 长按主页键切换”，启用开关并保存。先识别主页键，微信还需启用原有的微信扩展。移动和滚动速度各有五档，默认标准。关闭窗口不影响后台使用。

右侧“查看按键模式”可预览普通／鼠标两套操作，左侧产品图旁同步显示每个按键的作用。它不会切换实际运行模式；实际状态在蓝牙标记下方显示。鼠标固定操作不可改为快捷键，微信返回键、电视键及主页短按等共用设置仍可编辑。进入设置窗口会退出实际鼠标模式，详见[按键设置说明](KEY_SETTINGS.md#普通模式与鼠标模式)。

在已识别的 Codex 或微信前台，长按主页键约 0.6 秒进入鼠标模式，再长按退出。短按主页键在松开时执行原有配置，例如 Super；长按不会同时触发短按动作。切换时请先松开其他按键。

| 按键 | 鼠标模式行为 |
| --- | --- |
| 四个方向 | 移动光标；短按微调，按住逐渐加速；松手停止 |
| 确认 | 短按松开时左击；长按约 0.6 秒右击，不额外左击 |
| 音量＋／－ | 上下滚动光标所在区域；长按连续滚动；此模式不调音量 |
| 返回（Codex） | Esc，关闭菜单或取消 |
| 返回（微信） | 沿用微信返回键配置，默认 Backspace，支持长按连续退格 |
| 电视、电源及其他未占用按键 | 沿用该应用的原有映射；如微信电视键 Alt+A 截图 |
| 语音 | 提示先点击输入框并退出鼠标模式，不触发客户端听写 |

进入后屏幕边缘持续显示“鼠标模式 · 长按主页退出”。状态条不获得键盘焦点，鼠标点击可以穿透。提示条不可用时不会进入鼠标模式。

浏览时，移动到左侧聊天列表并点击即可换聊天；移到消息区域后用音量键滚动。回复时，点击输入框，长按主页退出，再用原来的语音键听写和确认发送。微信鼠标模式下点到输入框，可以直接用返回键退格；程序不会自动判断窗口内部的编辑焦点。

微信截图快捷键继续可用；第一阶段框选仍需实体鼠标。截图工具若使用无法识别的独立窗口，会退出鼠标模式，不把未知窗口强行当作微信。原生 Wayland 窗口的前台识别不在本次支持范围。

## 依赖与实现范围

现有桥接仍使用 SayAll 0.3.0。鼠标由独立的 `SayAll Remote Mouse` uinput 设备产生，状态条通过 GTK 3 / XWayland 显示，设置界面仍为 GTK 4。Ubuntu / Debian 可补充：

```bash
sudo apt install python3-gi python3-cairo gir1.2-gtk-3.0
```

不安装本地语音模型，不调用共享桌面门户，不改变默认音频设备、音量或 PipeWire / WirePlumber 设置。鼠标设备只写事件，不要求开放其他输入设备的读取权限。启用后第一次更新桥接运行文件需重新加载桥接；后续在界面调整速度和开关自动生效。

配置在既有 `keymap.json` 中增加一个可选字段：

```json
"navigation": {
  "enabled": true,
  "pointer_speed": 3,
  "scroll_speed": 3
}
```

开关及速度与原有映射一起保存、撤销；不覆盖三组应用映射。速度仅接受 1 到 5，主页键未识别时阻止保存启用设置。

## 释放与故障处理

切换应用类别、更新配置、进入按键检测或断开遥控器时退出鼠标模式；已开始的操作被取消，等待物理松手。短按确认在完成前切走应用，不补发点击。鼠标层在 SayAll 的语音与确认回调之前截获事件，按键服务再检查模式状态，防止迟到的命令误启动听写或发送。

持续移动不依赖遥控器的重复事件。定期读取这只遥控器的物理按键状态，遗漏松开事件时停止动作；连续持有方向或滚动键超过 10 秒会停止，松开再按即可继续。普通听写仍使用既有的独立生命周期和播放保护。

暂停后台会停止映射和麦克风，也关闭鼠标提示条。请注意，停止桥接后原始蓝牙按键仍可能由系统接收。
