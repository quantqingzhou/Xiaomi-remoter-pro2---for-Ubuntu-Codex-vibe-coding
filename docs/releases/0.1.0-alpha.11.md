# 小米蓝牙遥控器 2 Pro · Linux Codex · alpha.11

本次预发布增加独立的鼠标右键：进入全局鼠标模式后，单按遥控器菜单键即可在光标处右击。

## 本次更新

- 菜单键按下立即完成一次鼠标右击，长按及重复事件不连发；不额外发送普通菜单快捷键。
- 设置窗口的产品图标签、离线按键列表及功能说明明确显示“鼠标右键”；未识别时显示“待识别”。鼠标模式提示条同步显示菜单右击。
- 普通模式保留用户的菜单键配置；原来的长按确认键右击仍可使用。听写、发送、退格、鼠标移动和滚动沿用既有功能。

## 使用方法

1. 打开“小米遥控器按键设置”，选中菜单键。如果显示“待识别”，点击“识别菜单键”，轻按实体菜单键，然后保存。
2. 在“查看按键模式”中选“鼠标模式”，菜单键旁会显示“鼠标右键”。此处只切换说明预览。
3. 长按主页键约 0.6 秒进入实际鼠标模式，移动光标后按菜单键。再次长按主页退出。

## 下载与更新

下载 `.zip` 或 `.tar.gz` 完整源码包；`.sha256` 用于校验。阅读 `README.md` 或 `README.en.md` 后，按原安装方式更新运行文件并保留个人配置。仅下载或解压不会更新已有安装。

已安装用户需让桥接和设置窗口使用同一版本：更新后在空闲、所有遥控器按键已松开的情况下重新加载项目的 `sayall-bridge.service`，并重新打开设置窗口。无需重新配对，也无需调整 PipeWire、系统音量或默认音频设备。菜单键未识别时，更新代码不会替用户猜测按键码，仍需完成上述识别和保存。

## 验证范围

315 项公开源码测试和 40 项本机桥接测试通过。本机用户已识别保存菜单键，并确认单按右击正常、长按不连发；原应用映射和鼠标速度保持不变。其他设备、发行版、长期使用及本次更新后的整机重启未重新验收，继续标记为 **Pre-release**。

## English

This pre-release adds a dedicated right-click to the remote's Menu button in global mouse mode. Pressing Menu produces one right-click at the pointer; holding it or receiving repeat events does not trigger additional clicks. The normal-mode Menu mapping is retained, and long-holding OK still right-clicks.

The settings diagram, offline button list and action details use **鼠标右键** (Mouse right button). Unidentified Menu buttons show **待识别** (Needs identification). Select Menu, click its identification button, press the physical button and save. Choose **鼠标模式** to preview the labels; hold Home for about 0.6 seconds to actually enter or exit mouse mode.

Download a complete ZIP or tar.gz archive and verify it with the SHA-256 file. Update the installed runtime through your original installation method while retaining your personal configuration. After updating, reload the project's `sayall-bridge.service` while idle with all remote buttons released, and reopen settings. Downloading an archive alone does not update an installation. No Bluetooth re-pairing or system audio changes are required.

315 public-source tests and 40 local bridge tests passed. The user verified Menu right-click and non-repeating hold behavior on a real RC003. Existing app mappings and mouse speeds were preserved. Other machines, long-term operation and a full reboot after this update have not been revalidated; this remains a pre-release.
