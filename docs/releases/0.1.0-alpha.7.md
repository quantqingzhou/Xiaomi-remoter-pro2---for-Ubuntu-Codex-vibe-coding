# 小米蓝牙遥控器 2 Pro · Linux Codex · alpha.7

为 Linux 版 Codex 用户设计。本版在原有按住听写、松开转写、确认发送的基础上，增加可选的 Codex／微信鼠标操作，并补齐可视化按键说明。

## 本次更新

- 长按主页约 0.6 秒进入／退出鼠标模式，短按保留原配置，例如 Super。
- 方向键移动鼠标，按住逐渐加速；确认键短按左击、长按右击；音量键上下滚动。移动与滚动速度各有五档。
- 微信鼠标模式的返回键沿用原配置，默认退格，支持长按连续删除；电视键等保留用户设置的截图快捷键。Codex 鼠标模式的返回键为 Esc。
- 界面可分别查看普通／鼠标模式，产品图旁显示功能标签；固定操作只读，共用配置可编辑，主页短按与长按分别解释。无产品图时仍可使用带说明的文字按钮。
- 蓝牙标记下方显示实际运行模式，独立于界面预览；常用后台按钮保持直观。关闭“×”不再依赖图标主题。
- 鼠标提示条不抢焦点、允许点击穿透；切换应用、改配置、检测按键或断线会取消鼠标操作，并补充漏松手与持续移动保护。

## 下载、启用与使用

下载附带的 `.tar.gz` 或 `.zip`，解压后阅读 `README.md`／`README.en.md`。这些是完整源码包；`.sha256` 用于校验归档。

升级前备份自己的配置，按原安装方式更新桥接、按键服务和界面运行文件。鼠标提示条需要 `python3-gi`、`python3-cairo`、`gir1.2-gtk-3.0` 及 XWayland；设置窗口使用 GTK 4。详见仓库的 `docs/MOUSE_NAVIGATION.md`。

鼠标操作默认关闭。在设置中识别主页键，展开“鼠标操作 · 长按主页键切换”，启用并保存。微信仍需单独安装、配置并启用已有扩展。

“查看按键模式”只预览功能，不启动鼠标模式。使用时在 Codex／微信前台长按实体主页键。要听写或发送，先点击输入框并退出鼠标模式，再按语音键或确认键。微信在鼠标模式下点到输入框后可直接退格。

## 验证与限制

本机公开源码 **264 项自动测试通过**。已在 RC003、Ubuntu GNOME／XWayland 环境验证主要实体鼠标操作、原听写发送，以及微信鼠标模式的退格、长按删除和松手停止；隔离窗口另验证虚拟鼠标事件、提示条穿透和界面配置流程。

此前版本的基础听写、重连和整机重启有实测记录；**新增鼠标版本的整机重启、真实掉线恢复、另一台干净系统安装尚未完成验收**。本版因此标记为 **Pre-release**。暂不提供拖拽、截图框选或自动聚焦输入框；原生 Wayland 窗口的前台识别不在支持范围。

本次升级不改变默认音频设备、应用音量或 PipeWire／WirePlumber 配置。既有客户端播放保护继续按文档检查，客户端更新覆盖后仍需核实兼容性。

## English

This pre-release adds optional mouse navigation for Codex and WeChat on Linux, plus a mode-aware visual key editor. Hold Home to toggle; directions move the pointer, OK clicks or right-clicks, and volume keys scroll. WeChat Back retains its configured action (Backspace by default, with hold-to-repeat); TV keeps its configured screenshot shortcut. Codex Back sends Esc in mouse mode.

Mouse navigation is off by default. Identify Home, enable the feature in settings, and save. The settings mode selector only previews actions; it does not activate mouse mode. Click the input field and leave mouse mode before dictating or sending. The indicator requires GTK 3 and XWayland; the settings window uses GTK 4. See `README.en.md` for setup.

264 local automated tests passed, and core physical controls were checked on one RC003/Ubuntu GNOME machine. Reboot and disconnection testing of the new mouse build, clean installation on another machine, and broader distribution support remain pending. Dragging, screenshot region selection, automatic input focus, and native Wayland foreground detection are not included. Audio routing and volume settings are unchanged by this update.
