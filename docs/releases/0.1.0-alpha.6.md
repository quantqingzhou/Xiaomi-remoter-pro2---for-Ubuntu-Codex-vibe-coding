# 小米蓝牙遥控器 2 Pro · Linux Codex · alpha.6

为 Linux 版 Codex 用户设计：按住遥控器语音键听写，松开结束，确认键发送。本版增加中文可视化设置、按应用自定义按键、连接状态与故障日志，以及后台暂停、恢复和登录自启动控制。

## 本次更新

- Codex、微信、其他软件分别配置按键；支持实体键识别、组合键录入、Super 预设、默认恢复及撤销。
- 应用图标、四角圆角界面和统一的菜单样式；桥接状态提示放在暂停 / 恢复按钮正下方，正常时保持隐藏。
- 独立故障通知、启动前依赖检查与有限重连；保留已验证的语音输入和发送流程。
- 修复暂停失败后重试、自启动通知偏好、跨应用松键及未映射键断线释放等边界问题。
- 配置保存等待桥接确认；损坏配置先备份再恢复；日志隐藏蓝牙地址和用户目录。
- 提供英文 README。微信语音输入需要额外安装和配置，详见仓库文档。

## 下载与使用

下载附带的 `.tar.gz` 或 `.zip`，解压后阅读 `README.md` 或 `README.en.md`。这些是完整源码包，不是一键安装的 deb 包；依赖、权限、配对及客户端播放保护按快速开始说明配置。`.sha256` 文件用于校验两个归档。

升级已有安装前先备份自己的配置，按原安装方式更新；不要把包含私人排障资料的工作目录整体覆盖到源码包中。

## 验证范围

本机 221 项自动测试通过。已在小米蓝牙遥控器 2 Pro RC003、Ubuntu GNOME 环境中验证基础听写、发送、重连和一次整机重启；本轮暂停 / 恢复、自启开关及听写发送的用户反馈为基本正常。通用安装到另一台电脑、长期稳定性和所有新增按键边界尚未全面验收，因此标记为 **预发布 / Pre-release**。

项目不修改 PipeWire / WirePlumber 的底层配置，也不持续改写其他应用音量。客户端播放保护仅处理已核实的辅助程序版本；更新覆盖后需按文档检查。
