# 小米蓝牙遥控器 2 Pro · Linux Codex · alpha.9

这次预发布修复开机或重连后的 F5 连发残留，解决由此引起的微信录音被打断、切回 Codex 自动开始录音或松手后不停的问题。

## 修复内容

遥控器唤醒时，桌面可能先收到原始 F5 按下。如果桥接在按住期间接管设备，松开事件就可能被截走，桌面继续认为 F5 按着。

- 先准备虚拟键盘，再等待所有实体按键松开、事件队列安静约 150 毫秒后接管。
- 清理接管前已由桌面处理的旧事件，避免重放为新的听写操作。
- 抓取瞬间如果又有按键按下，立即让出设备等待重试；设备消失或停止服务时清理等待资源。

启动日志提示等待松键时，请完全松开遥控器，接管完成后重新开始听写。日常可轻按方向键唤醒。已有的 Codex／Claude 听写、微信扩展、按键自定义和全局鼠标功能继续保留。

## 下载与更新

下载 `.zip` 或 `.tar.gz` 完整源码包，解压后阅读 `README.md` 或 `README.en.md`；`.sha256` 文件用于校验。

已有用户按原安装方式更新运行文件并保留自己的配置。此修复涉及 `startup_guard.py` 和 `sayall-reconnect.py`，更新后需在松开所有按键时重新启动遥控器桥接。仅下载新源码不会自动替换已安装的运行文件。详见[开机与重连说明](../RECONNECT.md)。

如果旧版已经留下连发状态，应先松开按键，再只针对这只遥控器断开并重新连接，以清除现有状态；新保护负责后续接管过程。本版不修改 PipeWire／WirePlumber 配置、应用播放音量或客户端听写快捷键，也不引入桌面共享权限。

## 验证范围

- 本机用户完成“微信 → Codex → 微信”交叉验收，三次均正常转写、松开结束，无串录或卡住。

继续标记 **Pre-release**。以上实物结果来自一台 RC003／Ubuntu GNOME 电脑；其他电脑、桌面环境、休眠恢复及长期稳定性仍待验证。

## English

This pre-release fixes a startup/reconnection boundary that can leave F5 repeating, interrupt WeChat dictation, or start Codex recording unexpectedly. If the desktop receives the remote's wake-up key press before the bridge takes exclusive control, it can miss the release.

The bridge now prepares its output device first, waits until all physical keys are released and the input queue has been quiet for about 150 ms, discards old events, and checks the key state again after grabbing. A competing press causes it to relinquish the device and retry.

Download the complete ZIP or tar.gz source archive and verify it with the SHA-256 file. Follow README.en.md to update the installed runtime while retaining your configuration. Restart the remote bridge with all buttons released after updating. Downloading source alone does not update an existing installation. If an older version has already left a key stuck, release all buttons and reconnect only the affected remote to clear that state.

299 source tests and 40 existing prototype tests passed. The user verified WeChat → Codex → WeChat dictation and reported completing a reboot before approving publication on 2026-11-17. This remains a pre-release tested on one RC003/Ubuntu GNOME machine. Audio configuration, application playback volume and client dictation shortcuts are unchanged; no desktop-sharing permission is added.
