# 小米蓝牙遥控器 2 Pro · Linux Codex · alpha.10

本次预发布增加遥控器电量显示，可以直接在设置窗口查看剩余电量。

## 本次更新

- 首页蓝牙状态旁显示电量百分比，“状态与日志”中增加“遥控器电量”一行。
- 窗口打开时约每 8 秒随现有状态刷新，连接和电量复用同一次只读蓝牙查询。
- 20% 及以下使用低电量颜色；断开、查询失败或设备未上报时显示“未知”，不沿用旧百分比。
- 保持现有界面风格和窗口宽度，不改听写、按键映射、鼠标模式或音频配置。

读数由遥控器上报，可能延迟更新；本版不估算剩余使用时长，也不增加低电量桌面弹窗。界面查询不会唤醒或重新连接设备。

## 下载与更新

下载 `.zip` 或 `.tar.gz` 完整源码包，解压后阅读 `README.md` 或 `README.en.md`；`.sha256` 文件用于校验。

从源码运行的用户更新目录后重新打开设置窗口即可。已安装用户按原安装方式更新运行文件，保留自己的配置；仅下载压缩包不会自动替换安装目录。新增电量显示涉及 `key_settings.py` 和 `settings_status.py`，无需为了该界面功能重新配对或重启音频／按键桥接。

## 验证范围

308 项公开源码自动测试通过。真实遥控器已读到 94% 电量；隔离 GTK 界面检查覆盖正常、低电量、0%、满电、未知、颜色恢复及状态面板，按键配置保持不变。低电量和断线显示使用模拟数据验证，没有实际耗尽电池。

继续标记为 **Pre-release**，实物验证环境为小米蓝牙遥控器 2 Pro（RC003）与 Ubuntu GNOME。其他设备或桌面环境可能不提供电量，此时显示未知。

## English

This pre-release adds a battery percentage beside the Bluetooth badge and a battery row in Status and logs. It shares the existing read-only Bluetooth query and refreshes about every eight seconds while the settings window is open.

At 20% or below, the indicator uses a low-battery color. Disconnected, unavailable or unreported values show **未知** (unknown), without retaining a previous percentage. Values come from the remote and may update with a delay. No remaining-runtime estimate or low-battery desktop notification is added; the query does not wake or reconnect the device.

Download a complete ZIP or tar.gz source archive and verify it with the SHA-256 file. Source users can reopen settings after updating. Installed users should update their runtime through their original installation method while retaining their configuration; downloading an archive alone does not update installed files. This UI addition does not require restarting the voice/key bridge or changing audio settings.

308 source tests passed. A real RC003 reported 94%, and isolated GTK checks covered normal, low, zero, full and unknown values, style recovery and the status panel. Low-battery and disconnected displays used simulated data. This remains a pre-release; devices that do not expose battery information display unknown.
