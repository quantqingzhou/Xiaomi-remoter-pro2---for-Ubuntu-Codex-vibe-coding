# 小米蓝牙遥控器 2 Pro · Linux Codex · alpha.8

本次预发布增加 Claude 桌面接入、全局鼠标模式，并修复 Home 打开 GNOME 程序总览后确认键偶尔无效的问题。

## 本次更新

- **Claude 听写与编辑**：按住语音键触发 Ctrl+D，松开停止录音并转写；确认键 Enter 发送，返回键 Backspace，支持长按删除、松手停止。使用 Claude 自带听写，无额外识别模型。
- **全局鼠标**：任意软件中长按 Home 约 0.6 秒进入／退出。方向移动、确认短按左击／长按右击、音量键滚动；切换软件保留模式，识别到应用类别变化时取消未完成的动作。微信和 Claude 保留退格，其他鼠标返回键为 Esc。
- **总览确认修复**：普通模式下，GNOME 明确报告活动概览打开时，确认键执行 Enter 选中窗口。关闭概览后恢复应用映射；不会因此给所有未知应用启用 Enter。
- **界面完整呈现**：新增 Claude 页，显示普通／鼠标操作。Claude 专用键只读，其余键显示实际共用配置并提供编辑入口；保留原三组配置文件格式。补齐 Home／确认说明及顶部版本号。

## 下载与使用

下载 `.zip` 或 `.tar.gz` 完整源码包，解压后阅读 `README.md` 或 `README.en.md`；`.sha256` 文件可用于校验。

Claude 接入默认关闭。先用实体键盘验证当前页面支持 Ctrl+D 按住听写、松开停止，再以 XWayland 启动 Claude，并按 `docs/CLAUDE.md` 配置精确的窗口类名。打开设置窗口的 Claude 页本身不会启用接入，也不会更改客户端启动方式。

鼠标操作默认关闭：识别 Home，启用“在所有应用中启用”并保存；界面的模式选项只负责预览。实际切换仍需长按实体 Home。听写、发送前先点击输入框并退出鼠标模式。状态条需要 GTK 3 和 XWayland，设置窗口需要 GTK 4；GNOME 总览识别需要 `gdbus`。依赖及说明见 `docs/MOUSE_NAVIGATION.md`。

已有用户按原安装方式更新源码和运行文件，保留自己的配置；本版不迁移按键配置。Claude 页的共用编辑入口会跳到“其他软件”，在那里保存的更改也会影响其他使用该组映射的软件。

## 验证范围

本机 **291 项公开源码自动测试通过**；另完成临时配置的 GTK 界面操作和截图检查。用户已在 RC003／Ubuntu GNOME 设备上确认 Claude 听写、发送、退格，全局鼠标，以及从不同软件多次打开总览并确认切换均正常。

本版标记为 **Pre-release**。新增功能的整机重启、长期使用、其他桌面环境及另一台干净电脑安装仍待验证。应用专用听写／退格依赖 XWayland 窗口识别；全局鼠标无需识别每个窗口。同一应用类别内的窗口切换不会被单独检测。暂不提供拖拽、截图框选或自动聚焦输入框。

不改变默认音频设备、应用音量或 PipeWire／WirePlumber 设置；既有播放保护继续生效。本轮界面收尾没有重启已验收的桥接服务。

## English

This pre-release adds optional Claude Desktop integration: hold Ctrl+D through the remote voice button, release to finish, press OK for Enter, and use Back for Backspace with repeat. Verify the shortcut in your client and configure its exact XWayland window class first. No additional speech model is installed.

Mouse mode now works globally and persists when switching applications. Hold Home to toggle, use directions to move, OK to click or right-click, and volume keys to scroll. WeChat and recognized Claude windows retain Backspace. Exit mouse mode before dictation or sending.

Normal-mode OK now selects a window while GNOME explicitly reports its Activities overview is open. The new Claude settings tab shows fixed keys and links to shared Other apps mappings without migrating the configuration format. The window also displays the version and explains overview controls.

291 local source tests and isolated GTK UI checks passed. The user verified the core physical workflows on one RC003/Ubuntu GNOME machine. Broader installation, reboot and long-term testing remain pending. These are complete source archives with SHA-256 checksums; see README.en.md for setup. Audio routing and volume settings are unchanged.
