# 中文按键设置

本功能随 `alpha.6` 实验版本提供。默认映射与原版一致；设置窗口关闭后，后台桥接继续使用保存的配置。

## 打开窗口

界面使用 GTK 4，Ubuntu / Debian 可单独安装界面依赖：

```bash
sudo apt install python3-gi gir1.2-gtk-4.0
```

从源码目录打开：

```bash
/usr/bin/python3 -B scripts/settings.py
```

新版安装程序还会创建“小米遥控器按键设置”应用菜单入口。窗口不启动或重启桥接，不修改声音设置。已安装旧版时，单独更新窗口还不足以让映射生效：桥接与按键服务也需要使用同一版本的运行文件。

## 设置方法

1. 在右侧面板顶部选择 Codex、微信或其他软件。微信仍需先启用已有扩展；“其他软件”包括未识别的窗口。
2. 点击左侧产品图上的真实按键位置，右侧显示其默认功能。首次打开会加载官网产品图，加载失败时可用文字按钮选择，详见[产品图说明](PRODUCT_IMAGE.md)。
3. 选择预设动作，或输入 / 用键盘录入组合键，如 `Ctrl+Z`、`Ctrl+Shift+Enter`。
4. 如果显示“待识别”，先点击“识别这个按键”，再轻按对应实体键；识别成功后点击“保存设置”。先显示“已保存，等待桥接读取”，桥接确认后显示“已保存，桥接已读取”，后续按键使用新配置。桥接离线、读取异常或配置尚未生效时，在暂停 / 恢复按钮正下方显示原因；正常时不常驻显示就绪标签。

底部“更多操作”中的“恢复本应用默认”只清除当前应用的自定义，需保存后生效。“撤销上次保存”会把上一次的设置取回窗口，检查后再次保存完成恢复。“重新载入”放弃窗口内未保存的修改。右上角“×”退出设置窗口；有未保存的修改时，可以返回编辑或放弃并关闭，后台遥控器继续运行。

## 状态、日志与后台运行

顶部显示蓝牙的“已连接 / 未连接 / 状态未知”，查询失败不会被当成已断开。点击蓝牙标记或底部“状态与日志”，可以一起查看蓝牙、实体按键设备、音频桥接、SayAll 麦克风、按键服务、听写播放保护和桌面故障提示。窗口打开时约每 8 秒在后台更新一次，检查基础状态不代表已经确认实际收音或云端转写正常。

日志读取这几个项目服务最近 24 小时内的最多 200 条记录，默认显示“错误与警告”，可以切换“全部日志”、刷新或复制。蓝牙地址和用户目录会隐藏；程序不把日志上传到网络。查看状态和日志不操作设备连接、不录音、不调音量。

首页右侧“录入键盘快捷键”下方提供常用后台运行控制：

- **暂停后台**：先停止故障通知，再停止 SayAll 与按键服务。停止的是自定义映射和遥控器麦克风；蓝牙设备的原始按键仍可能被系统接收，不等于禁用硬件。不关闭系统蓝牙或 PipeWire。
- **恢复运行**：启动本项目的按键与桥接服务，并恢复暂停前运行的通知服务。等待状态更新后再用遥控器。暂停记录保存在用户状态目录，关闭再打开窗口仍可恢复。
- **登录后自动启动**：决定下次登录是否自动运行。关闭此开关不停止当前运行；现在就想停止时，再点“暂停后台”。恢复自启动会恢复先前随之关闭的通知服务自启动状态，不自动启用原本关闭的通知。

服务操作进行中暂不关闭窗口，以免在完成前中断操作。这些按钮只调用本项目的 systemd 用户服务，不要求 sudo。面板读取标准安装配置；仅在标准配置不存在且没有显式覆盖路径时，兼容早期独立状态服务的本地配置，不自动迁移或覆盖它。自定义状态 socket 可用 `XIAOMI_STATUS_KEY_SOCKET` 指定绝对路径；非标准的自定义服务需自行管理。

主页键想打开 GNOME 活动概览时，直接选择预设 **Super（打开活动概览）**，无需在录入模式按实体键盘的 Super。它每次触发只发送一次 Super 按下 / 松开，长按不连发。若希望在所有软件生效，需要分别保存 Codex、微信、其他软件三组的主页键配置。不同桌面可能赋予 Super 不同作用。

暂停失败后可以重试，程序保留原通知状态。自启开关完成操作后会读回状态；无法确认时不会报告成功。测试实体键和快捷键录入会在服务操作前结束。

默认语音键仍负责按住收音、松开结束：Codex 为 F5，已启用的微信为右 Alt，其他软件只收音。这一版语音键不可改为普通快捷键，普通按键也不接受 F5 或右 Alt，以保持听写与播放保护流程。

听写时切换到另一应用类别，会释放原听写键；请先松开遥控器语音键，再开始下一次听写。快捷键录入支持翻页键、Shift+Tab 和小键盘回车。

确认键默认在 Codex / 已启用微信中发送 Enter；其他软件不执行动作。可自行改为组合键或禁用。仍在听写时，确认键不会执行新动作。普通组合键及显式配置的 Enter 每次物理按下执行一次，不随长按重复；退格、方向、翻页、音量等键支持重复。

## 检测实体按键

“测试实体按键”持续最多 30 秒，需让设置窗口保持前台。期间遥控器新按下的键只用于识别，不发送原来的按键动作，也不启动听写或麦克风。检测前已经按住的键仍允许正常松开。切换到其他窗口、关闭窗口或超过时间会结束检测；窗口异常退出后检测请求约 1.5 秒失效。检测中按住的键即使检测结束，也要先松开才能正常使用。

语音、确认、返回、四个方向和音量键已有明确的事件码。电源键默认延续 SayAll 的拦截行为，可显式配置动作。主页、菜单、电视键不预设未经本机核实的事件码：先在示意图选择对应按键，点击“识别”后轻按并松开实体键，程序自动完成名称绑定，再保存即可。已有绑定可通过“更多操作 → 重新识别当前按键”调整。未完成实体键识别的自定义动作会阻止保存，并明确显示缺少哪一个按键。旧版遗留的未绑定配置仍可读取，但会提示待识别，避免误报已经可以使用。重复事件码或与已知按键冲突的绑定会被拒绝；如果检测没有收到事件，本功能不能凭空恢复硬件未上报的按键。

## 配置与故障行为

映射保存在 `~/.config/xiaomi-codex-remote/keymap.json`，上一版在同目录 `keymap.previous.json`。支持 `XDG_CONFIG_HOME`；专用覆盖变量为 `XIAOMI_KEYMAP_CONFIG`，使用时窗口和两个后台服务必须一致。文件只含动作和必要的按键码，不含蓝牙地址、语音内容或识别服务密钥。卸载不会清除用户后续保存的映射。

保存采用校验、锁与原子替换；如果另一个窗口或编辑器已经修改文件，会拒绝覆盖并要求重新载入。运行时遇到无效配置，继续使用该进程最后有效的配置并写日志；首次启动没有有效配置时使用默认值。切换应用类别、修改配置、设备断开和关闭服务会释放正在按住的输出；配置变化时必须松手再按，避免旧动作继续执行。

检测状态与最后一个检测事件仅写入当前用户的运行时目录，过期后不再拦截按键。窗口不监听普通电脑键盘；只有主动点击“用键盘录入组合键”时，接收本窗口的键盘事件。

配置损坏时，“更多操作”会出现“备份损坏配置并恢复默认”。确认后先将原始内容另存为同目录的 `keymap.invalid-*.json`，再恢复三组默认映射；不会覆盖 `keymap.previous.json`。恢复期间如果文件被另行修改，会拒绝覆盖。过大、符号链接或无权限文件需先自行处理，程序不会绕过这些限制。

暂不支持双击动作、独立的长按动作、应用启动或多步骤宏。不同前台应用仍沿用现有的 XWayland 窗口识别范围；窗口内部焦点需由用户选择。
