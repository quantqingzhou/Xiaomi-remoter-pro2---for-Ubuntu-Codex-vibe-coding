# 微信语音输入：可选扩展

本项目主要服务于 Linux 版 Codex。`0.1.0-alpha.3` 将本机原型中的微信按键映射整理为可选扩展：微信在前台时，语音键按下／松开对应右 Alt 按下／松开，确认键对应 Enter。语音通过遥控器麦克风输入，由 Fcitx5 Vinput 转为文字。

**默认关闭，需要用户自行安装和配置。** 本项目只提供按键映射，不安装输入法、识别模型或云端服务，不复制本机的密钥和设置。微信扩展不会自动使用 Codex 的云端听写。当前已通过模拟按键测试，微信内实际收音、转写、发送及音频兼容性仍待验证。

## 先准备输入法和识别服务

1. 按 [Fcitx5 Vinput 上游说明](https://github.com/xifan2333/fcitx5-vinput)安装适合自己发行版和处理器架构的版本，并让微信使用 Fcitx5。本机原型已安装 `fcitx5-vinput 2.4.2-1`；这只是参考环境，不代表所有版本已验证。
2. 自行配置 Vinput 的语音识别后端。上游支持本地和云端识别：需要本地模型或云端服务凭据时，按所选方案配置。不要把这些凭据写入本项目源码或提交到 GitHub。
3. 将 Vinput 的“按住说话”快捷键设为 **右 Alt（`Alt_R`）**，模式必须是按住开始、松开结束。若需要遥控器确认键直接发送，微信的发送快捷键应设为 Enter。
4. 启动遥控器桥接后，检查系统中有 **SayAll Mic**（`sayall-mic`），让 Vinput 使用它。先点入微信输入框，用实体键盘按住右 Alt，同时按住遥控器语音键提供麦克风音频，确认松开后能出字。

先完成实体键盘测试，再启用遥控器映射。若实体右 Alt 本身不能听写，先排查 Fcitx5、Vinput 后端、快捷键和麦克风，不要用遥控器映射掩盖这些问题。

## 启用微信窗口映射

用下面的命令点击微信窗口，读取 `WM_CLASS`：

```bash
xprop WM_CLASS
```

程序忽略大小写，但按完整类名精确匹配；不按窗口标题或部分字符串匹配。下面的 `wechat`、`weixin` 只是常见示例，应按自己机器的实际结果填写。

新安装时，在主说明的安装命令中增加参数，先预览，再按完整安装流程应用：

```bash
/usr/bin/python3 -B scripts/manage.py install --address AA:BB:CC:DD:EE:FF \
  --wechat-window-class wechat --wechat-window-class weixin
```

确认计划并完成必要的客户端播放保护后，按[主安装说明](../README.md#3-先预览再安装用户文件)停止旧服务，再给上述命令追加 `--apply`。微信扩展不替代 Codex 所需的播放保护。

已安装 `alpha.3` 时，在本项目生成的 `config.json` 中设置：

```json
"wechat_wm_classes": ["wechat", "weixin"]
```

配置通常位于 `~/.config/xiaomi-codex-remote/config.json`，使用自定义 XDG 目录时以实际安装路径为准。修改后运行 `systemctl --user restart sayall-bridge.service`，再执行 `scripts/doctor.py` 检查基础依赖。旧版 `alpha.2` 不支持该配置项；应先按旧版[卸载与回退](../README.md#卸载与回退)流程移除用户文件，再安装新版本。升级桥接时无需恢复已生效的客户端播放保护。

安装清单会保护用户修改过的文件。手动修改配置后若需要卸载，应先将该字段恢复为安装时的值，再执行卸载，避免将“拒绝覆盖后续修改”误认为故障。

## 验证和关闭

点入微信消息输入框，按住遥控器语音键说话，松开后等文字出现并检查；确认内容和接收对象后再按确认键发送。录音键仍按住时不会发送 Enter。返回键在微信中保持原始 `KEY_BACK`，不映射为退格。

分别测试正常松开、蓝牙断线、切回 Codex，以及音乐播放时多次听写。按住期间切换窗口不会把原键转换为另一个听写键；松开时释放原先按下的键。最长按住和断线释放保护同样覆盖右 Alt。

设置 `"wechat_wm_classes": []` 并重启桥接即可关闭此扩展，不必卸载 Vinput。关闭后微信按“其他软件”处理，不注入右 Alt 或 Enter。

本项目不会为微信扩展修改播放音量或 PipeWire / WirePlumber 配置，但 Vinput 及所选后端的行为仍需单独验证。SayAll 按键期间会切换默认麦克风，其他跟随系统默认输入的软件可能受影响。
