# Claude 桌面三键接入（alpha.8）

此扩展随 `alpha.8` 预发布版提供。普通模式映射语音、确认和返回三个键；另支持全局鼠标模式，设置窗口提供独立 Claude 页。

- 语音：遥控器按住时按下 Ctrl+D，松开时先释放 D 再释放 Ctrl。
- 确认：发送一次 Enter；仍按住听写键或等待物理松开时不发送。
- 返回：Backspace，支持连续退格，松手或切换应用后停止。

使用 Claude 自带的转写服务，不安装额外识别模型或借用微信的 Vinput。请先在需要使用的 Claude 页面，使用实体键盘确认 Ctrl+D 确实是按住开始、松开停止。界面不同区域、版本或客户端可能行为不同；没有验证此快捷键时不要启用扩展。听写前点入消息输入框。

当前桥接通过 X11 的 WM_CLASS 判断前台。Claude 若使用原生 Wayland，需要以 `claude-desktop --ozone-platform=x11` 启动并检查实际窗口类名；只改变应用启动方式，不改变桌面会话或声音设置。不要在有任务运行时强制结束 Claude。

通用安装的可选参数为 `--claude-window-class`，可重复指定已实测的窗口类名；对应本地配置字段 `claude_wm_classes`，默认空列表关闭。类名不能与 Codex／微信重复，不能使用浏览器类名来代表 Claude 网页。设置窗口新增 Claude 页，语音、确认和返回显示为专用固定操作；剩余普通按键显示“其他软件”的当前配置，通过“编辑共用设置”入口跳转修改。配置文件保留原先三组映射，不额外迁移；Claude 页的恢复本应用默认不可用，避免误清空共用设置。仅打开此页不会自动启用 Claude 听写。

开启[全局鼠标操作](MOUSE_NAVIGATION.md)后，在 Claude 长按主页约 0.6 秒进入／退出；方向移动、确认点击／长按右击、音量滚动。鼠标模式中返回键仍为 Backspace，支持长按删除；听写和 Enter 发送前先退出鼠标模式。切换应用保留模式，但已按住的动作在识别到类别变化时取消，松手再按。

按住期间切换应用、物理按键丢失或超时会释放 Ctrl+D。组合键输出部分失败时仍尝试释放 Ctrl。它不会改写默认音频设备、播放音量或 PipeWire／WirePlumber 配置；收音效果和客户端是否有额外音量行为，需要实际使用验证。

当前记录：Claude Desktop 5.11492.5，用户已确认鼠标点语音按钮可转写，实体 Ctrl+D 按住开始、松开停止。278 项源码测试及本机回归测试通过；用户随后确认遥控器语音、确认发送、返回键退格及长按删除全部正常。随后全局鼠标集成完成，用户已确认 Claude 和其他软件鼠标操作、退出后的原有听写／发送／退格均正常。

本机启动入口已改为用户维护的 XWayland 入口，保留原桌面快捷动作；移除客户端的自动生成标记后，当前版本会尊重此用户覆盖。更新客户端后仍需复验窗口类名和快捷键。三键新增功能的整机重启、其他设备和长期音频兼容性尚未验收。
